## Assignment Overview

The assignment consists of four programming problems:

| Problem | Description | Language |
|---|---|---|
| P1 | Department Assignment Puzzle, Reloaded | Prolog |
| P2 | Form a Valid Arithmetic Equation | Prolog |
| S1 | Binary Tree Traversals | Scheme (Racket) |
| S2 | Conditionally Insert into a Nested List | Scheme (Racket) |

### P1 — Department Assignment Puzzle
Generate valid assignments of departments, programming languages, and project preferences for four friends. Implement individual clue predicates, count valid solutions, and introduce a ninth clue to obtain a unique solution.

### P2 — Form a Valid Arithmetic Equation
Generate valid arithmetic equations from an ordered list of non-negative integers using arithmetic operators and exactly one equality operator.

### S1 — Binary Tree Traversals
Implement binary tree traversal operations and calculate tree height and leaf count using recursive Scheme functions.

### S2 — Conditionally Insert into a Nested List
Implement recursive operations on nested lists, including conditional insertion and higher-order functions.

## Development Workflow

We use a structured, two-model Generative AI workflow to develop and review our solutions.

### Model 1 — ChatGPT: Prompt Architect

ChatGPT acts as the Prompt Architect.

Its responsibilities include:

- Analysing the assigned problem statement and relevant language-specific skill file.
- Breaking down the problem into small, independent implementation tasks.
- Organising tasks in dependency order.
- Preparing separate prompts for implementation, testing, debugging, and code review.
- Ensuring compliance with the assignment's strict task-decomposition requirement.

Each implementation task is restricted to one predicate, function, helper, test file, or review.

### Model 2 — Gemini / Claude: Implementation Assistant

A second GenAI model acts as the Implementation Assistant.

It receives:

- The assigned problem statement.
- The relevant `SKILL.md` file.
- The specific implementation prompt generated by the Prompt Architect.

Its responsibilities include:

- Implementing only the requested unit of work.
- Following the language-specific coding conventions and restrictions.
- Briefly explaining implementation decisions.
- Suggesting focused test cases.
- Maintaining compatibility with previously implemented components.

### Integration and Verification

Generated implementations are reviewed before being integrated into the repository.

The development process follows these steps:

1. Obtain a narrowly scoped implementation prompt.
2. Generate the requested implementation using Model 2.
3. Review the generated code for correctness and compliance.
4. Integrate the code into the appropriate source file.
5. Record the exact prompts used in the corresponding `prompts/` file.
6. Commit and push incremental changes to GitHub.
7. Run tests and perform comprehensive code reviews.

This approach maintains modularity, traceability, and a meaningful Git commit history.

## Development Principles

Our implementation process follows these principles:

- **Strict decomposition:** Each implementation task addresses one clearly defined unit of work.
- **Declarative and functional programming:** Prefer logical relationships, recursion, and pure functions.
- **Constraint compliance:** Respect the permitted libraries, built-ins, and language-specific restrictions.
- **Incremental development:** Implement, review, and integrate components progressively.
- **Testing:** Use positive cases, negative cases, and relevant edge cases.
- **Traceability:** Maintain prompt histories and meaningful Git commits.
- **Code ownership:** Review and understand generated implementations rather than accepting them blindly.
